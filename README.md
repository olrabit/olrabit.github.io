# 개발자 웹사이트 (olrabit.github.io)

GitHub Pages 저장소 `olrabit/olrabit.github.io` 에 그대로 올리는 파일들. 이 폴더가 원본이다.

| 주소 | 파일 | 용도 |
|---|---|---|
| https://olrabit.github.io/ | `index.html` | 스토어 등록정보의 개발자 웹사이트 |
| https://olrabit.github.io/app-ads.txt | `app-ads.txt` | AdMob 판매자 확인 (iOS · Android 공통) |
| https://olrabit.github.io/its-not-lag/privacy/ | `its-not-lag/privacy/index.html` | 개인정보처리방침 (`docs/privacy/index.html` 복사본) |

- `app-ads.txt` 는 **도메인 루트**에 있어야 한다. `olrabit/app-ads` 저장소(`olrabit.github.io/app-ads/app-ads.txt`)는 하위 경로라 AdMob 이 읽지 않는다.
- 한 도메인에 app-ads.txt 는 하나다. 같은 AdMob 계정(pub-1990227606631674)이면 앱이 몇 개든 이 한 줄로 된다. 다른 광고 네트워크를 붙이면 그 줄을 아래에 더한다.
- 개인정보처리방침을 고치면 `docs/privacy/index.html` 을 고친 뒤 여기로 복사해서 다시 올린다.
